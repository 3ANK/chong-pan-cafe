## ที่มาของข้อมูลและการอัปเดต

`menu.json` เป็นสำเนารายการและราคาฐานที่ตรวจจากหน้าสั่งอาหาร ณ วันที่ระบุ รวมรายการเพิ่มเติมที่เจ้าของร้านแจ้ง (ลาบหมู 60 บาท และสามชั้นทอดน้ำปลา 80 บาท) ไม่ได้ซิงก์อัตโนมัติ เมื่อเปลี่ยนราคาในระบบสั่งอาหาร ให้ตรวจสอบและแก้ `menu.json` พร้อมวันที่ `verified_date` แล้วสร้างตารางและ CSV ใหม่ด้วย:

```sh
python3 scripts/export-menu.py
```

อาหารและขนมปรับชื่อและราคาตามรายการล่าสุดที่เจ้าของร้านแจ้งวันที่ 25 ตุลาคม 2026 รวมการย้ายข้าวเหนียวไปหมวดข้าวและไข่สั่งแยก และแยกราคาไข่สั่งเดี่ยวออกจากราคาเพิ่มไข่ในเมนูข้าว ขนมปังแยกชาไทยและใบเตยเป็นคนละรายการในราคาเดียวกัน

`assets/promo-products.js` ใช้สำหรับรูปสินค้าแนะนำบนหน้าเว็บไซต์เท่านั้น ไม่ใช่รายการเมนูทั้งหมด จึงไม่ควรใช้ยืนยันความครบถ้วนของราคาเครื่องดื่ม

การแก้ไฟล์เอกสารเหล่านี้ไม่เปลี่ยนราคาหรือรายการในระบบสั่งอาหาร
